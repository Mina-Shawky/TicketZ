## 📌 About The Project

**TicketZ** is an online movie ticket booking system built using the **MVC Architecture**.

The application provides users with an easy and interactive experience to browse available movies, create accounts, log in, add movie tickets to their shopping cart, and complete purchases using PayPal.

It also includes an administrative dashboard that allows administrators to manage movie records and control the platform's content through CRUD operations.

### 🎥 Movie Browsing
- Display available movies.

- Explore the available movie collection.

## 🏗️ Architecture

The project follows the **Model-View-Controller (MVC)** architectural pattern.

- **Model:** Handles application data and business entities.
- **View:** Responsible for displaying the user interface.
- **Controller:** Handles user requests and application logic.

- **C#** – Application development.
